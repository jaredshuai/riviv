### 2. 失败链重写(票面「写死」的落地)

- **init**:`gpu::create` 失败(auto 已含 hw→warp 两臂错误串;`d2d`/`warp` 单驱动诊断同理)→ `fatal()`(带诊断串)。原来的 latch+状态栏闪现+「session 留在 gdi」语义整体消失;ADR 0001 分类从用户级升系统级,**ADR 0002 D7 已预告,本票补 ADR 后记**。
- **运行时非丢失确定性错误**(现 `Unrecoverable`:EndDraw/Present 的非 loss HRESULT)→ **延迟 fatal**(`gpu_pending_fatal` + `gpu=None` + invalidate,paint_view 尾部开火)——不再降级会话。
- **rebuild 失败**(ladder 的 create 再失败)→ 同上延迟 fatal。
- **`gpu_init_failed` 语义终结**:字段删除;防「pending-fatal 窗口内先 rebuild」由 `paint_view` 重排保证(先查 `gpu_pending_fatal` 再考虑 rebuild,或等价 latch——实现期定,测试钉住)。
- **#82 移交项②落地**:`paint_d2d` 的 prepare `Err` 臂(现仅 blank+逐帧 stderr)加**连续失败计数**:连续 3 次 prepare 失败 → 视同 `DeviceLost` 进既有 ladder(rebuild 同种 → 3-in-10s 升 WARP → WARP 再 3 次 fatal)。计数器在 GpuStack、成功即清零;dump 路径不经此(一次性)。这使「driver 持续 CreateBitmap 失败但不掉设备」从永久空白+每帧重试变成有界升级,#82 PR #91 AI3 处置表「录+移交:与 #90 失败链重构一起做」兑现。

### 3. 迁移面:ini 的 `renderer=gdi`

#80 期 ini 显式存过 `renderer=gdi`(保存恒写当时值,ADR 0002 D5 后记)。处置:**config 加载时 `gdi` 一律映射 `auto` + stderr 一行迁移注记**(`riviv: renderer=gdi was removed, using auto`)——不用「unrecognized value」的既有兜底(那是误导:该词合法、只是臂没了)。`to_ini` 永不再写 gdi;round-trip 测试改为「gdi → auto + 注记」断言。逐字面澄清:**键保留解析**(四词词表收窄为三词+一个迁移映射),不删除键本身。
